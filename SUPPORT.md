# Support

Please use GitHub Issues for reproducible bugs, installation problems, and feature requests. Include:

- operating system and Python version;
- the demo and commit or release used;
- the smallest command or fixture that reproduces the issue;
- the complete error message and whether optional Graphviz/Matplotlib support is installed.

Questions about unpublished physics decisions or private data should not be posted with confidential material. The public repository only supports the documented demo scope.
