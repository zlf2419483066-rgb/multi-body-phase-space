## 怎样阅读

1. 在[图清单](01_图清单.md)选择母拓扑，查看原图和各标记分支的并排对照。
2. 点击标记类编号进入对应公式页；页首就是该类的图，下方是六步推导与最终公式。
3. PNG 可直接查看，SVG 可下载放大；公式 Markdown 可在 GitHub 阅读，也可下载后用 Obsidian 打开。

共提供 54 张母图、143 张代表标记图、72 页对照图，每张均有 PNG 与 SVG，共 **538 个图文件**。143 份公式正文和图文件沿用既有审阅包，没有在本次上传中重新推导或生成。

## 计数与审阅状态

143 是完整标记的换名等价类数；3363 是相应的固定标记身份数。运动学中的正负根或镜像解是另一种分支，具体约定见各公式页，不能与标记类数量混计。

当前公式有限定物理域内的局部数值核验，逐式人工审阅仍待完成。详见[来源与验证边界](资料/来源与验证边界.md)、[人工审阅记录](03_人工审阅记录.md)和[项目验证范围](../../docs/validation.md)。本目录是已有研究成果快照，不代表最终软件发布或全域证明。
