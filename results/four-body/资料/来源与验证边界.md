# 来源、计数与验证边界

本目录发布既有四体全圈公式 run04 与 2026-10-09 图形审阅包中的成果：54 个母拓扑、143 个标记公式类、3363 个固定身份映射。正文、PNG/SVG 图文件和原始证据压缩包均从已有成果复制；本次主要增加 GitHub 阅读入口。

143 是完整标记的换名等价类数。公式中的正负根或镜像解属于运动学逆像分支；它们不增加标记类或固定身份数量。内部方位角保留为连续坐标时，应按照对应公式的开区间和密度约定处理。

当前适用范围为四维正质量、母粒子高于阈值、非退化非共面开域及已选定的 D0 约定。有限点数值通过不等于全域证明，也不等于研究者已经逐式验收。所有人工审阅记录保持原有未审阅状态。

公式页保留当时的状态字段。页首 Yu2022 `verified_local` 对应原 Table 5/7 的限定密度与坐标换元核验，不能解释为全部论文公式已经通过。后续 22 表审查中，Table 21/26 原式问题、Table 23/24 角度测度约定等仍需分别处理，详见[项目验证范围](../../../docs/validation.md)。
